# Frontend Life OS

Frontend ini menggunakan React, TypeScript, Vite, Vitest, dan Playwright.

Perintah dari root repository:

```powershell
npm ci --prefix frontend/LifeOS.Web
npm run dev --prefix frontend/LifeOS.Web
npm run test --prefix frontend/LifeOS.Web
npm run lint --prefix frontend/LifeOS.Web
npm run build --prefix frontend/LifeOS.Web
```

Panduan menjalankan full test dengan PostgreSQL disposable dan Playwright ada di [README utama](../../README.md#automated-testing).
